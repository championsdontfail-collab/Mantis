# Mandatory design rules — approved by project owner, 2026-10-21

1. **NO OVERLAYS**: Never place a panel, label, button or text on top of an existing printed panel, label, button or text in a mockup image. No duplicate controls or hidden/covered original lettering.
2. **NO REDRAWING**: Do not redraw, recreate, approximate or replace the approved squirrel, scenery, signs, buttons, ornaments, typography or other illustrated elements with substitutes.
3. **INSERT ORIGINAL ASSETS**: Extract and insert the original approved artwork elements from the supplied mockup. Preserve their exact appearance.
4. For variable text, use original **blank** artwork elements; if only text-baked images exist, acquire or prepare a clean blank original asset first. Do not mask printed text with another box.
5. Keep the squirrel fully visible, use exactly one working action button per intended action, and keep navigation unduplicated.
6. Check **every screen and transition** in a browser before delivering. Test correct answers, wrong answers, Next, timer, completion after 20 questions, and rewards. Do not claim verification without running it.
7. The earlier builds violated these requirements and are not approved.

These rules take precedence over earlier implementation suggestions in this repository. Status: instructions saved; current deployed game is not yet compliant.
